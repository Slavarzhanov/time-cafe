## 2. Тестовые файлы

```
internal/server/*_test.go     рендеринг шаблонов через httptest
web/testdata/                 эталонные фрагменты HTML (если нужны)
```

Проверка рендеринга:

```go
rec := httptest.NewRecorder()
srv.Routes().ServeHTTP(rec, httptest.NewRequest("GET", "/", nil))
// проверить код 200, наличие ключевых узлов, отсутствие inline style
```

Если доступен браузерный инструмент, дополнительно проверяем консоль, сеть и
скриншот на 1366×768. Без него — ручной чек-лист и HTML-тесты.

## 2. Тестовые файлы

```
internal/billing/*_test.go       табличные тесты расчёта
internal/server/*_test.go        httptest, коды ответов, RBAC
internal/domain/*_test.go        валидация UID, статусы
internal/storage/*_test.go       интеграция с тестовой БД (пишет qa-db)
```

Правила:

- Табличные тесты: `name`, вход, ожидание, без `time.Sleep`.
- Время передаётся явно, не берётся из `time.Now()` внутри теста.
- HTTP-тесты — через `httptest.NewServer`/`httptest.NewRecorder`.
- Для БД — только `timecafe_test`, не рабочая база.

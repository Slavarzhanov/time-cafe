# Предметная область TimeCafe

Краткая карта домена. Полные формулировки — в [`ТЗ.md`](../../ТЗ.md).

## 1. Что делает система

Веб-приложение для тайм-кафе: администратор выдаёт гостю оборотную карту,
открывает визит в комнате/зоне, добавляет услуги, закрывает визит и принимает
оплату одной суммой. Система считает стоимость времени по правилам комнаты,
применяет скидку гостя, фиксирует платежи и формирует отчёты.

## 2. Участники

| Роль | Что может |
|---|---|
| **Администратор (`manager`)** | рабочее место: смены, гости, карты, визиты, услуги, оплата, отчёты |
| **Управляющий (`admin`)** | всё то же + сотрудники, роли, настройки, справочники |
| **Гость** | не имеет учётной записи; участвует в визите, хранит историю и скидку |

## 3. Ключевые сущности

| Сущность | Смысл | Важное |
|---|---|---|
| **Гость** | клиент заведения | история и скидка принадлежат гостю |
| **Карта** | физический пропуск EM-Marine | оборотная: выдана на визит, возвращена после |
| **Комната** | оплачиваемый ресурс: зал, комната, зона | цена за час, `min_minutes`, `rounding_minutes` |
| **Визит** | пребывание гостя с картой в комнате | открыт → закрыт; не больше одного активного у гостя |
| **Услуга** | напитки, еда, игры, печать | цена фиксируется в момент добавления |
| **Платёж** | поступившие деньги | наличные, карта, перевод; сумма = итог визита |
| **Бронь** | резерв комнаты на интервал | активные брони одной комнаты не пересекаются |
| **Смена** | период работы администратора | визит принадлежит открытой смене; лимит 12 часов |
| **Скидка** | правило уменьшения стоимости времени | принадлежит гостю; не больше стоимости времени |

## 4. Жизненный цикл визита и карты

1. Администратор открывает смену.
2. Гость выбирает комнату; администратор выдаёт свободную карту.
3. Карта временно связывается с визитом (не с гостем навсегда).
4. Открывается визит: гость, карта, комната, смена, время старта.
5. Услуги добавляются в визит; цена каждой фиксируется.
6. При закрытии система считает время, применяет скидку, суммирует услуги.
7. Принимается оплата; сумма платежей должна совпасть с итогом.
8. Карта возвращается в пул и может быть выдана следующему гостю.
9. История и скидка остаются у гостя, а не у карты.

## 5. Инварианты (из ТЗ, раздел 4.3)

| ID | Инвариант |
|---|---|
| И-1 | Деньги — только целые числа в копейках; `float`, `money`, `numeric` недопустимы |
| И-2 | Итог визита = стоимость времени + услуги − скидка, все величины ≥ 0 |
| И-3 | Визит нельзя закрыть дважды; у закрытого заполнены `finished_at` и суммы |
| И-4 | Время визита неотрицательно, `finished_at ≥ started_at` |
| И-5 | У гостя не больше одного активного визита |
| И-6 | Карта участвует не более чем в одном активном визите |
| И-7 | Карта, не вернувшаяся из визита, не может быть выдана повторно |
| И-8 | Нельзя добавить или удалить услугу в закрытом визите |
| И-9 | Цена и название услуги в чеке — на момент добавления, не текущие |
| И-10 | UID карты уникален и соответствует `^[0-9A-F]{10}$`; номер на карте уникален |
| И-11 | Сумма платежей закрытого визита равна итогу |
| И-12 | Цена и правила округления комнаты неизменны, пока в ней есть активный визит |
| И-13 | Активные брони одной комнаты не пересекаются по времени |
| И-14 | Визит принадлежит открытой смене; смену нельзя закрыть с активными визитами |
| И-15 | Скидка не превышает стоимость времени |

## 6. Расчёт стоимости времени

- Единица — комната: `price_per_hour`, `min_minutes`, `rounding_minutes`.
- Фактическое время округляется вверх до шага `rounding_minutes`.
- Применяется минимум `min_minutes`.
- Скидка гостя применяется к стоимости времени и не может превысить её.
- Услуги считаются отдельно: `qty × price_at_moment`.
- Итог: `time_amount + services_amount − discount_amount`.
- Все суммы — `BIGINT` в копейках.

## 7. Что запрещено моделью

- Постоянная привязка карты к гостю (`cards.guest_id` как «владелец»).
- Баланс карты и списание с баланса.
- Привязка скидки или истории к карте.
- Хранение денег в `float`/`numeric`/`money`.
- Хранение времени без часового пояса.
- Выдача карты, которая ещё не вернулась из визита.
- Закрытие смены с активными визитами.

# Интерфейс TimeCafe

Владелец раздела — агент `frontend`; визуальный язык и компоненты — агент
`style` ([стайлбук](../design/stylebook.md)).

## 1. Каркас

`web/templates/layout.html`:

```
topbar (brand + nav)
  └─ main.content
       └─ {{template "content" .}}
  └─ footer
```

- `lang="ru"`, кодировка UTF-8.
- Один CSS-вход: сейчас `/static/app.css`; после разбиения — `tokens.css` +
  `base.css` + `components/*.css` + `pages/*.css`.
- Никаких inline-стилей и CSS-фреймворков.

## 2. Экраны

| Экран | Маршрут | Шаблон | Статус |
|---|---|---|---|
| Смена / главный | `/` | `index.html` | каркас, скан-заглушка |
| Вход | `/login` | — | план |

Статус обновляется после каждого вертикального среза.

## 3. Структура CSS (цель)

```
web/static/css/
  tokens.css        переменные: цвета, отступы, радиусы, шрифты
  base.css          reset, типографика, ссылки, фокус
  components/       кнопки, поля, таблицы, карточки, бейджи, модалки
  pages/            стили конкретных экранов
web/static/app.css  временная точка входа; разбирает style
```

Правило: `frontend` не редактирует `tokens.css`, `base.css` и `components/`.
Нужен новый компонент или токен — запрос агенту `style`.

## 4. Правила интерфейса

- **Язык** — русский; подписи, ошибки и пустые состояния на русском.
- **Базовая ширина** — 1366×768; проверять также 1280×720 и 1920×1080.
- **Клавиатура.** Все действия доступны с клавиатуры; `Tab` идёт по логичному
  порядку; `Esc` закрывает модалку; основные действия — с горячими клавишами.
- **Фокус** всегда видим (не `outline: none` без замены).
- **Формы.** У каждого поля `<label>`; ошибка рядом с полем; введённое значение
  не теряется при ошибке.
- **Состояния.** У каждого экрана есть пустое, загрузочное и ошибочное состояние.
- **Деньги.** В БД копейки, на экране — рубли с двумя знаками: `1 250,00 ₽`.
- **Дата и время.** Локальная зона заведения, `дд.мм.гггг чч:мм`.
- **UID карты** — 10 hex-символов в верхнем регистре, моноширинный шрифт.
- **HTMX.** Фрагменты возвращают HTML; после действия обновляется только
  нужный блок, без перезагрузки страницы.
- **Доступность.** Контраст текста ≥ 4.5:1, кнопки имеют текстовую подпись или
  `aria-label`, изображения — `alt`.

## 5. Чек-лист экрана

- [ ] Работает на 1366×768 без горизонтальной прокрутки.
- [ ] Пустое состояние объясняет, что делать.
- [ ] Ошибка сети/сервера видна и не теряет введённые данные.
- [ ] Все поля с подписями, ошибки привязаны к полям.
- [ ] Клавиатура проходит сценарий целиком.
- [ ] Фокус видим, порядок `Tab` логичный.
- [ ] Нет inline-стилей и новых цветов вне токенов.
- [ ] Текст на русском, без английских заглушек.
- [ ] HTMX обновляет только нужный фрагмент.

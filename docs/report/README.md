# Рабочее место агента `report`

Здесь живёт текст пояснительной записки / реферата и результаты его проверки.
Агент `report` — единственный, кто пишет в этот каталог.

## Файлы

| Файл | Что это | Кто меняет |
|---|---|---|
| `реферат.md` | источник текста, обычный Markdown | `report` |
| `реферат.docx` | собранный документ для сдачи | `report` через `pandoc` |
| `замечания.md` | найденные проблемы и статус проверки | `report` |

## Сборка `.docx`

`.docx` — бинарный формат. **Не редактируй его инструментами `edit`/`write`.**
Источник истины — `реферат.md`, документ пересобирается командой:

```powershell
pandoc docs/report/реферат.md -o docs/report/реферат.docx
```

Если нужен шаблон оформления (поля, шрифт, стили заголовков):

```powershell
pandoc docs/report/реферат.md `
  --reference-doc=docs/report/шаблон.docx `
  -o docs/report/реферат.docx
```

Если `pandoc` не установлен — не подменяй `.docx` текстовым файлом. Собери
`реферат.md`, напиши в отчёте, что нужен `pandoc`, и укажи команду.

## Что проверять

1. **Соответствие ГОСТ 34.602 / методичке кафедры:** структура, нумерация,
   подписи рисунков и таблиц, список источников, приложения.
2. **Соответствие фактам:** схема БД, маршруты, названия таблиц и полей,
   суммы, сроки — сверять с `ТЗ.md`, `migrations/`, `internal/`, `web/`.
3. **Соответствие ТЗ:** все функции П1 описаны; инварианты И-1…И-15 не
   противоречат тексту; критерии К-1…К-14 отражены.
4. **Язык:** единый стиль, без разговорных оборотов, англицизмов без нужды,
   «ё» либо везде, либо нигде.
5. **Оформление:** единый шрифт, интервалы, выравнивание, подписи, ссылки на
   рисунки и таблицы.

## Формат замечания

```
[Критично] Раздел 3.2, с. 41
Что: в тексте `cards.guest_id` описан как постоянная привязка карты к гостю.
Почему: противоречит ТЗ D6 и docs/knowledge/domain.md.
Как исправить: карта привязывается к визиту; постоянной привязки нет.
```

Уровни: **Критично** (фактическая ошибка/несоответствие ТЗ), **Существенно**
(структура, ГОСТ, пропущенный раздел), **Стиль** (формулировки, оформление).

## Границы

- `report` не правит код, миграции, шаблоны и стили.
- Нужен факт по БД — спроси `db`; по API — `backend`; по экрану — `frontend`.
- Не выдумывай результаты замеров, скриншоты и числа. Если данных нет —
  оставь `[нужно измерить]` и вынеси в замечания.

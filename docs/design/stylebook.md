# Стайлбук TimeCafe

Версия 0.1 · владелец — агент `style` · обновляется вместе с `web/static/css`.

Стайлбук задаёт единый визуальный язык. `frontend` использует готовые токены и
компоненты, а не вводит свои цвета и размеры на отдельных экранах.

## 1. Принципы

1. **Спокойный рабочий интерфейс.** Администратор смотрит на экран всю смену:
   меньше декора, больше читаемости.
2. **Одно главное действие на экране.** Кнопка с акцентом одна; остальные —
   вторичные.
3. **Состояние важнее красоты.** Пусто, загрузка, ошибка, успех — всегда видны.
4. **Клавиатура — первый класс.** Сканирование карты и горячие клавиши не
   должны требовать мыши.
5. **Никаких магических чисел.** Цвета, отступы и радиусы — только из токенов.

## 2. Токены

```css
:root {
    /* поверхности и текст */
    --bg: #f4f5f7;
    --surface: #ffffff;
    --text: #1c1f23;
    --muted: #6b7280;
    --border: #e3e6ea;

    /* акцент и статусы */
    --accent: #2563eb;
    --accent-hover: #1d4ed8;
    --success: #1a7f37;
    --warning: #b45309;
    --danger: #b42318;

    /* форма */
    --radius: 10px;
    --radius-sm: 6px;
    --radius-pill: 999px;

    /* отступы: шаг 4 px */
    --space-1: 4px;
    --space-2: 8px;
    --space-3: 12px;
    --space-4: 16px;
    --space-6: 24px;
    --space-8: 32px;
    --space-12: 48px;
}
```

Правило: новый цвет сначала добавляется в `tokens.css` с осмысленным именем,
затем используется. Прямые `#hex` в `components/` и `pages/` запрещены.

## 3. Типографика

| Роль | Размер | Начертание |
|---|---|---|
| Основной текст | 15 px / 1.5 | 400 |
| Подпись, метаданные | 13 px / 1.4 | 400, `--muted` |
| Заголовок страницы `h1` | 22 px / 1.25 | 700 |
| Заголовок блока `h2` | 18 px / 1.3 | 600 |
| Кнопка | 15 px | 600 |
| Числа в таблицах | 15 px, `tabular-nums` | 400 |

Шрифт: `"Segoe UI", system-ui, sans-serif`. Моноширинный — для UID карты:
`"Cascadia Mono", "Consolas", monospace`.

## 4. Сетка и отступы

- Контент: `max-width: 1080px`, по центру, боковые отступы 20 px.
- Внутренние отступы карточки: 24 px.
- Расстояние между блоками: 24 px; внутри формы — 12–16 px.
- Радиус: 10 px у карточек и полей, 6 px у мелких элементов.
- Брейкпоинты: 1280, 1366 (базовый), 1920. Мобильная версия — не приоритет MVP.

## 5. Компоненты

### Кнопки

| Вариант | Фон | Текст | Когда |
|---|---|---|---|
| Primary | `--accent` | белый | главное действие экрана |
| Secondary | `--surface` + рамка | `--text` | альтернативное действие |
| Danger | `--danger` | белый | удаление, отмена визита |
| Ghost | прозрачный | `--accent` | действие в строке таблицы |

Состояния: `hover`, `focus-visible` (кольцо 2 px `--accent`), `disabled`
(прозрачность 0.55, `cursor: not-allowed`), `loading` (текст + спиннер).

### Поля ввода

- Высота 40–44 px, рамка `--border`, радиус `--radius`.
- `focus`: рамка `--accent` + внешнее кольцо, без смещения макета.
- Ошибка: рамка `--danger`, текст ошибки 13 px под полем.
- Подпись всегда сверху, не placeholder вместо подписи.

### Карточка

`background: var(--surface)`, рамка `--border`, радиус `--radius`, padding 24 px.
Заголовок и описание — по типографике выше.

### Таблица

- Заголовок: 13 px, `--muted`, uppercase не используем.
- Строки: разделитель `--border`, высота 44 px.
- Числа выровнены вправо, `tabular-nums`.
- Действия — в последней колонке, ghost-кнопки.

### Бейдж статуса

| Статус | Цвет |
|---|---|
| активен / оплачен | `--success` |
| ожидает / предупреждение | `--warning` |
| закрыт / отменён / ошибка | `--danger` |
| нейтральный | `--muted` |

Фон бейджа — тот же цвет с прозрачностью 12%, текст — насыщенный.

### Пустое состояние

Заголовок 18 px, одна строка объяснения, одно действие. Не оставляем пустой
экран без подсказки.

### Модальное окно

- Затемнение `rgba(0,0,0,.35)`, карточка по центру, максимум 480 px.
- `Esc` закрывает, фокус переходит в первое поле и возвращается обратно.
- Кнопка подтверждения — справа, отмена — слева.

## 6. Доступность

- Контраст обычного текста ≥ 4.5:1, крупного ≥ 3:1.
- Фокус видим всегда; `outline: none` без замены запрещён.
- Интерактивные элементы — `<button>`/`<a>`, не `<div onclick>`.
- Иконка без текста — `aria-label`.
- Ошибки формы связаны с полем через `aria-describedby`.
- Никакой информации только цветом: статус подписан словом.

## 7. Чего не делаем

- Не вводим второй акцентный цвет «для красоты».
- Не используем тени вместо рамок для разделения блоков.
- Не ставим текст на цветной фон без проверки контраста.
- Не делаем анимации дольше 200 мс и не анимируем таблицы.
- Не используем иконочные шрифты и внешние CDN.
